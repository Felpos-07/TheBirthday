# Surpresa de aniversário

Site estático e mobile-first para uma surpresa de aniversário.

## Como abrir

Abra `index.html` diretamente no navegador ou rode um servidor local simples, por exemplo:

```bash
npx vite --host
```

## Como colocar a foto

Depois de abrir o presente, toque em **colocar uma foto nossa** e escolha uma imagem do celular. A imagem é usada apenas naquela sessão do navegador.

Para deixar uma foto padrão no site, troque o valor de `src` da imagem `#birthdayPhoto` em `index.html` por uma URL pública da foto.
